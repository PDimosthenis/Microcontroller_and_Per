# Έξυπνο Σύστημα Ελέγχου Πρόσβασης (ARM Assembly)

Αυτό το project υλοποιεί έναν αλγόριθμο υπολογισμού "Access Hash" (Επίπεδο Πρόσβασης) για ένα έξυπνο σύστημα ασφαλείας. Ο πυρήνας του αλγορίθμου είναι γραμμένος εξ ολοκλήρου σε **ARM Assembly (32-bit)**, ενώ η δοκιμή και επαλήθευση του κώδικα (Testbench) γίνεται μέσω **C**.

## Περιγραφή Αλγορίθμου
Η συνάρτηση Assembly `access_hash` δέχεται ένα αλφαριθμητικό (PIN) και παράγει ένα μοναδικό Hash βάσει των εξής κανόνων:
1. Η αρχική τιμή του Hash ισούται με το μήκος του string.
2. Για κάθε αριθμό ('0'-'9'), προστίθεται μια σταθερά από έναν Look-up Table (LUT) που βρίσκεται στη μνήμη.
3. Για κάθε κεφαλαίο γράμμα ('A'-'Z'), προστίθεται η ASCII τιμή του πολλαπλασιασμένη επί 2 (μέσω LSL).
4. Για κάθε πεζό γράμμα ('a'-'z'), μετατρέπεται πρώτα σε κεφαλαίο μέσω Bitwise AND μάσκας (`0xDF`) και έπειτα προστίθεται στο Hash.
5. Οποιοσδήποτε άλλος χαρακτήρας αγνοείται.

## Δομή Αρχείων
* `hash.s`: Ο πηγαίος κώδικας της ARM Assembly.
* `main.c`: Το Testbench σε C που τρέχει 100 τυχαία αυτοματοποιημένα tests για να επαληθεύσει την ορθότητα της Assembly.
* `Makefile`: Σκριπτ αυτοματοποίησης για τη μεταγλώττιση και την εκτέλεση.
